ВИСНОВКИ:

Під час виконання практичної роботи №8 було досліджено дисципліну обслуговування LIFO (Last In, First Out) та реалізовано структуру даних Стек.

1. Реалізація ArrayStack<T>:
Стек на базі масиву є дуже швидким, оскільки всі операції виконуються за константний час O(1). Основний недолік — фіксований розмір. Для вирішення цієї проблеми було реалізовано перевірку на переповнення (Stack Overflow) з генерацією відповідного винятку.

2. Реалізація LinkedStack<T> (Варіант 1):
Стек на базі однозв'язного списку вирішує проблему обмеженої місткості. Додавання елемента (Push) відбувається на початок списку, а вилучення (Pop) — з початку. Це дозволяє досягти складності O(1) для всіх базових операцій без необхідності зсуву елементів. Головний компроміс — додаткові витрати пам'яті на зберігання вказівників (посилань) на наступний вузол.

Обидві реалізації успішно пройшли тестування, включаючи обробку порожнього стеку та переповнення.
